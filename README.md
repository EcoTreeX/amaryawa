# Amaryawa Farms — GitHub Pages

Static website ready for GitHub Pages.

## Deploy
1. Upload all files in this folder to the root of your GitHub repository.
2. Commit and push.
3. In **Settings → Pages**, choose **Deploy from a branch**, select your main branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish.

The HTML pages include an inline CSS fallback, so the design will still render even if `styles.css` is not loaded by the host.
